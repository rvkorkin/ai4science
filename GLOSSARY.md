# GLOSSARY.md — символы, термины, единицы

Каждый символ или термин в тексте статьи — через эту таблицу. Если нужно что-то новое —
сначала запись здесь, потом в тексте.

## Символы и величины

| Символ | Значение | Единицы | Где |
|---|---|---|---|
| `t` | время (локальное, от начала записи) | мин (после децимации) / с (сырое) | — |
| `i, k` | индексы по времени | — | формулы причинности |
| `d, z` | глубина вдоль волокна | м | — |
| `D` | число каналов глубины в окне | — | `(T, D)` формат npz |
| `T` | длина записи по времени | сэмплы | — |
| `R` | фактор децимации (dt_out/dt_in) | — | обычно 6 (10с → 1мин) |
| `dt_sec` | шаг по времени | с | 60 после децимации |
| `dz` | шаг по глубине (медианный) | м | 0.4–2.0 (разные интеррогаторы) |
| `s(t, z)` | strain | безразм. (nε или относ.) | — |
| `ṡ(t, z)` | strain rate | 1/с | `dr` в коде |
| `w(t)` | ширина клина в момент `t` | м | сходит к 0 на `t_hit` |
| `t_hit` | время прихода трещины (hit) | мин | обозн. `tpk` в коде |
| `d_hit` | глубина хита | м | `d_frac` в литературе |
| `η(t, z)` | ETA-оценка времени до хита | мин | `wedge_near.py::eta_series` |
| `σ_t` | джиттер временно́й метки (MAD) | мин | в soft-labels |
| `σ_d` | джиттер глубинной метки | м | в soft-labels |
| `AUC` | ROC-AUC | — | пер окно (window-level) или пер файл |
| `FAR` | False-Alarm Rate | — | рабочая точка FAR ≤ 0.10 (K4) |
| `recall@FAR` | recall при фиксированном FAR | — | — |
| `Δ` | парная разность метрики | — | в K4: `AUC_leaky − AUC_causal` |
| `d_z` | Cohen's d_z (размер эффекта для парных) | — | — |
| `δ` | практический порог значимости для `Δ` | — | 0.05 в K4 |

## Термины

| Термин | Короткое определение |
|---|---|
| **LF-DAS** | low-frequency distributed acoustic sensing: оптоволокно как многоточечный датчик strain-rate в полосе 0.01–1 Гц |
| **Frac-hit (hit)** | момент прорыва ГРП-трещины в мониторинговую скважину; event-level и time-level задача |
| **Wedge (клин)** | двулучевой strain-rate signature вокруг хита: «сердце», сходящееся в нить к `t_hit` (Liu 2020, Leggett) |
| **FWHM-collapse** | механизм клина: full-width-at-half-max ширины зоны `w(t)` → 0 на `t_hit` |
| **Causal preprocess** | предобработка, в которой выход в момент `i` зависит только от входа до `i·R` — нет look-ahead |
| **Look-ahead leak** | нарушение каузальности (напр. per-file нормировка по всей последовательности): завышает метрики |
| **Soft-labels** | распределения (μ, σ) вместо точечных меток; консенсус нескольких оценщиков |
| **Per-file normalization** | нормировка статистиками одной записи целиком — классический источник утечки, если применяется до разбиения train/val |
| **leave-one-GROUP-out** | схема CV, где группа = treatment event (стадия ГРП); у нас — не строгий leave-one-WELL-out |
| **pairloo OOF** | out-of-fold по парам «treatment/monitor-well» — честная оценка |
| **SeqCNNGRU** | архитектура проекта: CNN по глубине + GRU по времени |
