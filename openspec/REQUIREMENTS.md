# openspec/REQUIREMENTS.md — принятые требования к статье

Это «контракт» на статью: что должно быть, в каком виде, с какой проверкой приёмки.

---

## R1. Структура

Обязательные разделы (порядок жёсткий):
1. Заголовок + авторы + аффилиация.
2. Аннотация (≤ 10 строк).
3. Введение и постановка задачи.
4. Данные и предобработка.
5. Модель.
6. Проверка (verification) — пересказ ДЗ-2 §3–5 для читателя.
7. Результаты.
8. Ограничения.
9. Вывод.
10. Источники (≤ 10).
11. Использование ИИ-ассистентов (таблица, формат ДЗ-2 §9).

**Приёмка:** в `article.tex` есть все 11 разделов в указанном порядке (как `\section{…}` и один `\begin{abstract}`).

## R2. Факты и цифры

Каждая цифра и утверждение в тексте имеет **один** из двух источников:
- (а) **Литературный** — DOI или arXiv-ID работы из `LITREVIEW.md`.
- (б) **Экспериментальный** — артефакт из `checks/results/` (JSON/CSV/PNG).

**Приёмка:** в тексте нет чисел без ссылки на источник. Выдуманные DOI (например,
«10.2118/123456-PA») = провал приёмки.

## R3. Онтология и глоссарий

- Каждый символ в формуле — есть в `GLOSSARY.md`.
- Каждая именованная сущность (модель, датасет, метрика, явление) — есть в
  `ONTOLOGY.yaml`.
- Если термина нет — сначала правка `GLOSSARY.md` / `ONTOLOGY.yaml`, потом текст.

**Приёмка:** запустить `python checks/check_glossary.py` (TODO: написать) или
вручную — пробежать по каждому символу и имени.

## R4. Проверка

Раздел «Проверка» переписывается из ДЗ-2 (`REPORT.md` §3–5 ветки `hw2`), но:
- На языке статьи (не отчёта): без PowerShell-команд, без путей.
- С фокусом на **почему** это важно: каузальность → достоверность метрик.
- С количественной ценой нарушения: K4-эксперимент `ΔAUC ≈ +0.45` как мотив.

**Приёмка:** `pytest -q checks` на свежем клоне ветки `article` = зелёный.

## R5. Ограничения

Явный раздел с перечислением (минимум 3 пункта):
- что модель не проверяет формально (GRU-warmup);
- single-seed A/B на реальных данных;
- `well-group` пересечение 20 (нестрогий leave-one-WELL-out);
- K4 — синтетика (цена утечки, не абсолютные числа).

**Приёмка:** раздел «Ограничения» есть, ≥ 3 пункта, честный.

## R6. Авторство

- **Inline-пометки:** `[написано]`, `[порождено: модель]`, `[источник: ссылка]`.
- **Таблица в конце:** фрагмент / пометка / инструмент / чем проверено.

**Приёмка:** любая абзац-единица текста имеет пометку автора.

## R7. Длина

2–4 страницы A4, собранные XeLaTeX из `article.tex` (11pt, `geometry margin=2cm`,
`CMU Serif`).

**Приёмка:** `latexmk -xelatex article.tex` соберётся без ошибок,
`pdfinfo article.pdf | grep Pages` → значение ≤ 4.

## R8. Источники

Ровно **≤ 10** позиций. Все с DOI/arXiv-ID/URL. Все цитируются в тексте
(нет «мёртвых» источников).

**Приёмка:** в `refs.bib` ≤ 10 записей, каждая цитируется в `article.tex` через `\cite{…}` хоть раз.
