# Задача сценария

Написать в файл `bus/draft_N.md` короткий (3--5 предложений) фрагмент раздела
«Результаты» статьи для записи LF-DAS `scenario/fixtures/rec_hit.npz`.

Требования к черновику:

1. Один абзац, 3--5 предложений.
2. Указано имя файла записи (`rec_hit.npz`).
3. Указано оценённое время прихода frac-hit в минутах; число должно совпадать
   с тем, что возвращает `frac_hit_verify`, с точностью до $0{,}1$ мин.
4. Указано, что файл прошёл проверку схемы и физических инвариантов.
5. Текст без штампов и подводок (`важно отметить`, `как известно`, `играет
   ключевую роль`), без оценочных слов и восклицательных знаков.

Критик проверяет черновик:

- вызывает `frac_hit_verify` на той же записи и сверяет число минут;
- сверяет имя файла и наличие фразы «прошёл проверку»;
- считает число предложений (3--5);
- ищет запрещённые обороты по словарю (`scenario/lint_rules.txt`).

«Принято» ставится, только если все четыре проверки прошли.
